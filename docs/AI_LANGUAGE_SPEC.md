# UkrCode AI Language Specification

**Версія специфікації: 0.1.3**  
**Призначення:** цей файл є канонічним контекстом для ШІ, який генерує або
пояснює код UkrCode. Оновлюйте його разом із кожною зміною мови.

## Правила для генератора коду

1. Завжди використовуй розширення `.ucod`.
2. Використовуй українські ключові слова та назви API з цієї специфікації.
3. Відступ блоку становить чотири пробіли. Після `:` починається блок.
4. Секрети зберігай у `.env` і отримуй через `середовище("НАЗВА")`.
5. Не вигадуй API. Якщо можливість не описана тут, познач її як майбутню.
6. Асинхронний Telegram polling, callback queries та HTTP працюють через
   локальний runtime без AI-сервісів.

## Значення і вирази

```ucod
імʼя: текст = "Ярема"
вік = 12
активний = так
дані = {"імʼя": імʼя, "вік": вік}
числа = [1, 2, 3]
```

Літерали: текст у подвійних або одинарних лапках, цілі та дробові числа,
`так`, `ні`, `нічого`, списки `[...]`, словники `{ключ: значення}`.

Оператори: `+ - * / // % **`, `== != > < >= <=`, `і`, `або`, `не`.

Індекси та зрізи:

```ucod
перше = числа[0]
частина = числа[1:3]
дані["вік"] = 13
```

## Керування потоком

```ucod
якщо вік >= 18:
    написати("дорослий")
інакше якщо вік >= 13:
    написати("підліток")
інакше:
    написати("дитина")

для число у числа:
    написати(число)

поки вік < 18:
    вік += 1
```

Також доступні `повторити 3 разів:`, `перервати`, `продовжити`,
`спробувати:`, `помилка:`, `нарешті:` та `підняти Помилка(...)`.

## Функції

```ucod
функція привітати(імʼя, гучно = ні):
    якщо гучно:
        повернути "ПРИВІТ, " + імʼя
    повернути "Привіт, " + імʼя
```

Функції підтримують параметри, значення за замовчуванням, локальні змінні,
рекурсію та `повернути`. `асинхронна функція` і `чекати` зарезервовані для
майбутнього повного async runtime; не вигадуй для них додатковий API.

## Класи та обʼєкти

Клас може мати конструктор `ініціалізувати`, поля та методи. Перший параметр
методу conventionally називається `цей` і містить поточний обʼєкт.

```ucod
клас Користувач:
    функція ініціалізувати(цей, імʼя):
        цей.імʼя = імʼя

    функція привітатися(цей):
        повернути "Привіт, " + цей.імʼя

клас Адмін(Користувач):
    функція права(цей):
        повернути "повний доступ"

адмін = Адмін("Оля")
написати(адмін.привітатися())
```

Підтримуються конструктори, методи, властивості, виклик успадкованих методів
та просте наслідування через `клас Дочірній(Батьківський):`.

## Загальні вбудовані функції

Доступні без імпорту: `написати`, `введення`, `діапазон`, `довжина`, `тип`,
`текст`, `ціле`, `дробове`, `сума`, `мінімум`, `максимум`, `перелічити`,
`відсортувати`, `набір`. Наприклад:

```ucod
для число у діапазон(1, 4):
    написати(число)
```

## Створення бібліотек користувачів

Для прототипів і розширень дозволено виконувати Python прямо у `.ucod`:

```ucod
пайтон("""
def подвоїти(число):
    return число * 2
""")

написати(подвоїти(4))
```

Створені Python-функції, класи та змінні доступні далі в UkrCode. Обʼєкт
`ukrcode` у Python містить поточне середовище мови. Цей механізм має повні
права Python-процесу, тому його можна використовувати лише з довіреним кодом.

Бібліотека — це окремий каталог з `main.ucod` і `ucod.toml`. Для експорту
змінних, функцій і класів використовується ключове слово `експорт`.

```ucod
# mylib/main.ucod
експорт функція сума(а, б):
    повернути а + б

експорт функція привітати(імʼя):
    повернути "Привіт, " + імʼя

експорт клас Кошик:
    функція ініціалізувати(цей):
        цей.елементи = []
```

```toml
# mylib/ucod.toml
назва = "mylib"
версія = "0.1.0"
точка_входу = "main.ucod"
```

Потім бібліотеку можна встановити або імпортувати локально:

```bash
ucod нова-бібліотека mylib
ucod встановити ./mylib
ucod run app.ucod
```

```ucod
імпортувати mylib
результат = mylib.сума(2, 3)
написати(mylib.привітати("Оля"))
```

## Telegram bots

Токен має бути в `.env`:

```env
BOT_TOKEN=новий_токен_від_BotFather
```

Базовий bot:

```ucod
імпортувати Telegram
бот = Telegram.Бот(середовище("BOT_TOKEN"))

коли бот.команда("/start"):
    бот.відповісти("Привіт!", кнопки = [["Допомога", "Профіль"]])

коли бот.отримав_текст("Допомога"):
    бот.відповісти("Ось довідка.")

бот.запустити()
```

Доступні обробники:

- `бот.команда("/start")` — команда;
- `бот.отримав_повідомлення()` — будь-яке текстове повідомлення;
- `бот.отримав_повідомлення("привіт")` — конкретний текст;
- `бот.отримав_текст("привіт")` — конкретний текст;
- `бот.натиснули_кнопку("help")` — inline callback.

Кнопки:

```ucod
бот.відповісти("Меню", inline_кнопки = [[
    {"текст": "Допомога", "дані": "help"}
]])

коли бот.натиснули_кнопку("help"):
    бот.відповісти("Довідка")
```

Операції поточного повідомлення:

```ucod
повідомлення.відповісти("текст")
повідомлення.фото("https://example.com/image.jpg", "підпис")
повідомлення.документ("https://example.com/file.pdf")
повідомлення.редагувати("оновлений текст")
повідомлення.видалити()
```

Операції бота: `надіслати_фото`, `надіслати_документ`,
`редагувати_повідомлення`, `видалити_повідомлення`.

Сесії, адміністратори та замовлення доступні для bot applications:

```ucod
сесія = бот.сесія(повідомлення.користувач.id)
сесія.встановити("кошик", ["lua"])
кошик = сесія.отримати("кошик", [])

якщо бот.є_адмін(повідомлення.користувач.id):
    замовлення = бот.створити_замовлення(повідомлення.користувач.id, "Lua", 250)
    всі = бот.отримати_замовлення()
```

`ADMIN_IDS` у `.env` містить ID через кому. Сесії та замовлення зберігаються в
памʼяті процесу; для production їх потрібно підʼєднати до `БазаДаних`.

## Безпека і точність

Не вставляй реальний токен у `.ucod`, README, приклади або commit. Для
локального тесту використовуй `.env`, який ігнорується Git. Telegram Gateway,
FSM, middleware, Discord Gateway, повна система типів, LSP, debugger і
bytecode VM ще не є частиною стабільного API цієї версії.
