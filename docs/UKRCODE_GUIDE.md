# UkrCode: повний підручник мови

UkrCode — україномовна інтерпретована мова програмування. Файли мови мають розширення `.ucod`. Вона призначена для навчання програмуванню, невеликих CLI-програм, автоматизації, локальних інструментів і Telegram-ботів.

Версія цього посібника відповідає UkrCode 0.1.3.

## 1. Встановлення

### Найпростіший спосіб

Linux або macOS:

```bash
curl -fsSL https://raw.githubusercontent.com/UkrCodeOfficial/UkrCode/main/install.sh | bash
export PATH="$HOME/.local/bin:$PATH"
ucod --version
```

Перевірка першої програми:

```bash
cd "$HOME/.ukrcode"
ucod run examples/hello.ucod
```

### Встановлення з Git

```bash
git clone https://github.com/UkrCodeOfficial/UkrCode.git
cd UkrCode
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -e .
ucod --version
```

Для Windows найзручніше використовувати WSL або запускати UkrCode у Linux-контейнері VS Code. Для роботи з файлами `.ucod` встановіть VS Code extension із каталогу `vscode-extension`:

```bash
cd vscode-extension
npm install
npm run package
code --install-extension ./ukrcode-language-support-0.1.3.vsix --force
```

### Команди CLI

```bash
ucod run файл.ucod       # виконати програму
ucod файл.ucod           # скорочення для ucod run файл.ucod
ucod check файл.ucod     # перевірити синтаксис
ucod format файл.ucod    # додати фінальний перенос рядка
ucod repl                # інтерактивний режим
ucod test                # запустити тести проєкту
ucod --version           # показати версію
ucod --help              # довідка
```

Команди для проєктів і бібліотек:

```bash
ucod новий мійпроєкт
ucod нова-бібліотека моя-бібліотека
ucod встановити ./моя-бібліотека
ucod список
ucod оновити
ucod видалити моя-бібліотека
```

## 2. Перша програма

Створіть файл `привіт.ucod`:

```ucod
імʼя = "Оля"
написати("Привіт, " + імʼя + "!")
```

Запустіть його:

```bash
ucod run привіт.ucod
```

Результат:

```text
Привіт, Оля!
```

Коментар починається символом `#`:

```ucod
# Це коментар і він не виконується
написати("Програма працює")
```

UkrCode чутливий до відступів. Після двокрапки починається блок, а всі рядки цього блоку мають однаковий відступ. Використовуйте чотири пробіли.

```ucod
якщо так:
    написати("Цей рядок у блоці")
```

## 3. Значення та змінні

Змінна створюється присвоєнням:

```ucod
імʼя = "Ярема"
вік = 12
ціна = 49.90
активний = так
видалений = ні
порожнє = нічого
```

Можна вказати просту анотацію типу:

```ucod
імʼя: текст = "Ярема"
кількість: ціле = 3
```

Основні значення:

| Значення | Приклад |
|---|---|
| текст | `"Привіт"` або `'Привіт'` |
| ціле число | `42` |
| дробове число | `3.14` |
| логічне | `так`, `ні` |
| порожнє | `нічого` |
| список | `[1, 2, 3]` |
| словник | `{"імʼя": "Оля"}` |

Значення можна змінювати:

```ucod
лічильник = 0
лічильник += 1
лічильник -= 1
лічильник *= 2
лічильник /= 2
```

## 4. Оператори

Арифметика:

```ucod
сума = 2 + 3
різниця = 8 - 3
добуток = 4 * 5
частка = 7 / 2
ціла_частка = 7 // 2
остача = 7 % 2
степінь = 2 ** 3
```

Порівняння:

```ucod
а == б
а != б
а > б
а < б
а >= б
а <= б
```

Логіка:

```ucod
якщо вік >= 18 і має_документ:
    написати("Доступ дозволено")

якщо адміністратор або власник:
    написати("Розширений доступ")

якщо не заблокований:
    написати("Користувач активний")
```

## 5. Текст

```ucod
імʼя = "Оля"
повідомлення = "Привіт, " + імʼя + "!"
написати(повідомлення)
```

Перенос рядка позначається `\n`:

```ucod
написати("Рядок один\nРядок два")
```

Для складніших операцій використовуйте модуль `Текст`:

```ucod
імпортувати Текст

слово = "ukrcode"
написати(Текст.верхній_регістр(слово))
написати(Текст.довжина(слово))
```

## 6. Списки та словники

```ucod
мови = ["UkrCode", "Python", "JavaScript"]
написати(мови[0])
написати(мови[1:3])

користувач = {
    "імʼя": "Оля",
    "вік": 15
}
написати(користувач["імʼя"])
користувач["вік"] = 16
```

Індекси починаються з нуля. Елемент списку або словника можна змінити:

```ucod
числа = [1, 2, 3]
числа[0] = 10
числа[1] += 5
```

Корисні вбудовані функції:

```ucod
довжина(числа)
сума(числа)
мінімум(числа)
максимум(числа)
відсортувати(числа)
набір([1, 1, 2])
перелічити(["а", "б"])
```

## 7. Умови

```ucod
оцінка = 87

якщо оцінка >= 90:
    результат = "відмінно"
інакше якщо оцінка >= 60:
    результат = "складено"
інакше:
    результат = "потрібно повторити"

написати(результат)
```

Умова може бути складним виразом:

```ucod
вік = 20
є_квиток = так

якщо вік >= 18 і є_квиток:
    написати("Вхід дозволено")
```

## 8. Цикли

Цикл `для` перебирає колекцію:

```ucod
для імʼя у ["Оля", "Марко", "Іван"]:
    написати("Привіт, " + імʼя)
```

Для чисел використовуйте `діапазон`. Верхня межа не входить у результат:

```ucod
для число у діапазон(1, 4):
    написати(число)
```

Результат: `1`, `2`, `3`.

Цикл `поки` працює, доки умова правдива:

```ucod
лічильник = 0
поки лічильник < 3:
    написати(лічильник)
    лічильник += 1
```

Повторення задану кількість разів:

```ucod
повторити 3 разів:
    написати("ще раз")
```

`перервати` завершує цикл, а `продовжити` переходить до наступної ітерації:

```ucod
для число у діапазон(1, 10):
    якщо число == 5:
        перервати
    якщо число % 2 == 0:
        продовжити
    написати(число)
```

## 9. Функції

Функція оголошується ключовим словом `функція`:

```ucod
функція привітати(імʼя):
    повернути "Привіт, " + імʼя + "!"

повідомлення = привітати("Оля")
написати(повідомлення)
```

Параметр може мати значення за замовчуванням:

```ucod
функція додати(а, б = 1):
    повернути а + б

написати(додати(4))
написати(додати(4, 6))
```

Іменовані аргументи:

```ucod
функція створити_профіль(імʼя, вік):
    повернути {"імʼя": імʼя, "вік": вік}

профіль = створити_профіль(вік = 16, імʼя = "Оля")
```

Функції можуть викликати самі себе:

```ucod
функція факторіал(число):
    якщо число <= 1:
        повернути 1
    повернути число * факторіал(число - 1)

написати(факторіал(5))
```

## 10. Ввід, типи та перетворення

```ucod
імʼя = введення("Як тебе звати? ")
вік = ціле(введення("Скільки тобі років? "))
написати("Тобі " + текст(вік) + " років")
```

Вбудовані функції:

```ucod
тип(значення)
текст(значення)
ціле(значення)
дробове(значення)
довжина(значення)
діапазон(початок, кінець)
```

`тип` повертає назву типу, наприклад `"list"`, `"str"` або `"int"`.

## 11. Помилки

Для обробки помилок використовуйте `спробувати`, `помилка` і `нарешті`:

```ucod
спробувати:
    число = ціле("це не число")
помилка:
    написати("Не вдалося перетворити значення")
нарешті:
    написати("Цей блок виконається завжди")
```

Власну помилку можна підняти через `підняти`:

```ucod
функція перевірити_вік(вік):
    якщо вік < 0:
        підняти Помилка("Вік не може бути відʼємним")
    повернути так
```

## 12. Класи та обʼєкти

Клас описує власний тип обʼєктів. Метод-конструктор має назву `ініціалізувати`, а першим параметром методу за домовленістю є `цей`:

```ucod
клас Користувач:
    функція ініціалізувати(цей, імʼя):
        цей.імʼя = імʼя

    функція привітатися(цей):
        повернути "Привіт, " + цей.імʼя

користувач = Користувач("Оля")
написати(користувач.привітатися())
```

Клас може успадковувати інший клас:

```ucod
клас Адмін(Користувач):
    функція права(цей):
        повернути "повний доступ"

адмін = Адмін("Марко")
написати(адмін.привітатися())
написати(адмін.права())
```

Властивості зберігаються в полях обʼєкта, наприклад `цей.імʼя`.

## 13. Імпорти та стандартна бібліотека

Модуль підключається через `імпортувати`:

```ucod
імпортувати Математика як мат

результат = мат.округлити(12.345, 2)
написати(результат)
```

Доступні стандартні модулі:

| Модуль | Призначення |
|---|---|
| `Математика` | математичні операції |
| `Текст` | операції з текстом |
| `Списки` | робота зі списками |
| `JSON` | створення та розбір JSON |
| `Файли` | читання і запис файлів |
| `ОС` | змінні середовища та операції ОС |
| `Дата` | робота з датами |
| `Час` | час і затримки |
| `Випадковість` | випадкові значення |
| `РегулярніВирази` | пошук за шаблонами |
| `Термінал` | виконання термінальних операцій |
| `Процеси` | робота з процесами |
| `Логування` | журнали програми |
| `HTTP` | HTTP-запити |
| `БазаДаних` | SQLite |
| `Telegram` | Telegram Bot API і polling |
| `Discord` | Discord webhook |

Приклад JSON:

```ucod
імпортувати JSON

текст = JSON.створити({"імʼя": "Оля", "активний": так})
дані = JSON.розібрати(текст)
написати(дані["імʼя"])
```

Приклад SQLite:

```ucod
імпортувати БазаДаних

бд = БазаДаних.підключити("дані.sqlite")
бд.створити_таблицю("люди", {"імʼя": "текст", "вік": "число"})
бд.додати("люди", {"імʼя": "Оля", "вік": 16})
людина = бд.знайти_одного("люди", де = {"імʼя": "Оля"})
написати(людина)
```

## 14. Файли та змінні середовища

Секрети не записуйте в `.ucod`. Створіть `.env`:

```env
BOT_TOKEN=токен_бота
ADMIN_IDS=123456789,987654321
```

Отримайте значення в програмі:

```ucod
токен = середовище("BOT_TOKEN")
написати(токен)
```

Реальний токен не можна додавати в Git, README або приклади.

## 15. Telegram-боти

Створіть `.env` з токеном від BotFather:

```env
BOT_TOKEN=ваш_токен
```

Мінімальний бот:

```ucod
імпортувати Telegram

бот = Telegram.Бот(середовище("BOT_TOKEN"))

коли бот.команда("/start"):
    бот.відповісти("Привіт! Це UkrCode-бот.")

бот.запустити()
```

Запуск:

```bash
ucod run bot.ucod
```

Обробники повідомлень:

```ucod
коли бот.отримав_повідомлення():
    повідомлення.відповісти("Я отримав повідомлення")

коли бот.отримав_повідомлення("привіт"):
    повідомлення.відповісти("Вітаю!")

коли бот.отримав_текст("Допомога"):
    бот.відповісти("Ось довідка")
```

Звичайні кнопки:

```ucod
коли бот.команда("/start"):
    бот.відповісти(
        "Обери дію:",
        кнопки = [["Допомога", "Профіль"], ["Про бота"]]
    )
```

Inline-кнопки та callback:

```ucod
коли бот.команда("/start"):
    бот.відповісти(
        "Обери розділ:",
        inline_кнопки = [[
            {"текст": "Допомога", "дані": "help"},
            {"текст": "Про бота", "дані": "about"}
        ]]
    )

коли бот.натиснули_кнопку("help"):
    бот.відповісти("Це довідка")
```

Обʼєкт поточного повідомлення:

```ucod
повідомлення.відповісти("текст")
повідомлення.фото("https://example.com/image.jpg", "підпис")
повідомлення.документ("https://example.com/file.pdf")
повідомлення.редагувати("новий текст")
повідомлення.видалити()
```

Сесії, адміністратори та замовлення:

```ucod
коли бот.команда("/start"):
    користувач_id = повідомлення.користувач.id
    сесія = бот.сесія(користувач_id)
    сесія.встановити("кошик", ["скрипт"])

    якщо бот.є_адмін(користувач_id):
        бот.відповісти("Ти адміністратор")
```

`ADMIN_IDS` у `.env` — це ID користувачів через кому. Сесії та замовлення в поточній версії зберігаються в памʼяті процесу; для тривалого зберігання використовуйте `БазаДаних`.

UkrCode має простий Discord webhook, але це ще не повний Gateway-бот зі slash-командами та voice events:

## 17. Власні бібліотеки

### Python прямо у файлі `.ucod`

Для власного розширення можна виконати багаторядковий Python-блок прямо у
програмі:

```ucod
пайтон("""
def подвоїти(число):
    return число * 2

class Рушій:
    def стан(self):
        return "готовий"
""")

написати(подвоїти(21))
написати(Рушій().стан())
```

Функції, класи та змінні, створені в блоці, стають доступними нижче у файлі.
Змінна `ukrcode` у Python містить поточне середовище UkrCode, тому Python може
викликати його API через `ukrcode["написати"](...)` або отримувати значення
через `ukrcode["назва"]`.

Це навмисний escape hatch для розширень, прототипів і доступу до Python-пакетів.
Python-код має ті самі права, що й звичайний Python-процес: не запускайте
неперевірені `.ucod` файли та не вставляйте секрети в код.

Створіть бібліотеку:

```bash
ucod нова-бібліотека текстові-інструменти
```

Бібліотека має містити `main.ucod` і `ucod.toml`:

```toml
назва = "текстові-інструменти"
версія = "0.1.0"
точка_входу = "main.ucod"
```

У `main.ucod` позначте публічні елементи словом `експорт`:

```ucod
експорт функція подвоїти(число):
    повернути число * 2

експорт клас Лічильник:
    функція ініціалізувати(цей):
        цей.значення = 0
```

Встановіть бібліотеку в проєкт:

```bash
ucod встановити ./текстові-інструменти
```

Імпортуйте її:

```ucod
імпортувати текстові_інструменти

написати(текстові_інструменти.подвоїти(5))
```

Локальні пакети зберігаються у `.ucod/packages`, а список залежностей — у `ucod.lock`.

### Вкладені модулі та зовнішні рушії

Бібліотека може мати кілька `.ucod`-модулів:

```text
графіка/
├── main.ucod
├── сцена.ucod
├── камера.ucod
├── plugin.py
└── ucod.toml
```

Їх можна підключати окремо:

```ucod
імпортувати графіка.сцена як сцена
сцена.створити()
```

`plugin.py` — необовʼязковий адаптер для можливостей, яких немає в самому
інтерпретаторі: веб-фреймворків, 3-D рушіїв, аудіо, GUI, машинного навчання
або системних API. Він повертає словник `ucod_module`:

```python
import some_3d_engine

ucod_module = {
    "створити_вікно": some_3d_engine.create_window,
    "запустити": some_3d_engine.run,
}
```

Після встановлення бібліотеки UkrCode-код може викликати ці функції:

```ucod
імпортувати графіка

вікно = графіка.створити_вікно("Моя гра", 800, 600)
графіка.запустити(вікно)
```

Плагін має повний доступ Python-процесу, тому підключайте лише власні або
перевірені бібліотеки. Це міст між UkrCode і зовнішнім світом, а не окрема
магічна реалізація всіх веб- та 3-D API.

### Додаткові слова синтаксису

Для читабельності доступні синоніми: `вивести` і `надрукувати` для
`написати`; `процедура`, `метод` і `дія` для `функція`; `тип` і `шаблон` для
`клас`; `доки` для `поки`; `перебирати` для `для`; `повторювати` для
`повторити`; `тестувати` для `спробувати`; `обробити` для `коли`; `підключити`
і `долучити` для `імпортувати`; `оголосити` для `експорт`; `повернутися` для
`повернути`; `зупинити` для `перервати`; `пропустити` для `продовжити`.

Це синоніми, а не сто нових різних механізмів: нове слово має сенс лише тоді,
коли за ним стоїть чітка операція. Нові предметні слова для сайтів, графіки
чи ігор краще додавати у власну бібліотеку, а не вбудовувати в ядро мови.

## 18. Як організувати проєкт

Приклад структури:

```text
мійпроєкт/
├── main.ucod
├── README.md
├── .env
├── .env.example
├── ucod.toml
└── .ucod/
    └── packages/
```

`.env` містить локальні секрети й не має потрапляти в Git. У репозиторій можна додати `.env.example` без реальних значень.

## 19. Типовий процес розробки

1. Створіть файл `.ucod`.
2. Напишіть невелику частину програми.
3. Перевірте синтаксис через `ucod check файл.ucod`.
4. Запустіть через `ucod run файл.ucod`.
5. Винесіть повторювану логіку у функції.
6. Коли програма виросте, розділіть її на бібліотеки або модулі.
7. Для важливих даних додайте `БазаДаних`.
8. Перед публікацією приберіть токени та перевірте код у чистому середовищі.

## 20. План навчання

### Етап 1: основи

Вивчіть змінні, тексти, числа, списки, словники, оператори та `написати`. Напишіть:

- програму-привітання;
- конвертер температури;
- калькулятор двох чисел;
- список покупок.

### Етап 2: логіка

Вивчіть `якщо`, `інакше`, `для`, `поки`, `перервати` і `продовжити`. Напишіть:

- перевірку віку;
- таблицю множення;
- гру «вгадай число»;
- підрахунок суми та середнього списку.

### Етап 3: функції

Розділяйте програму на маленькі функції з одним завданням. Напишіть:

- функцію перевірки пароля;
- конвертер валют;
- меню термінальної програми;
- рекурсивний факторіал.

### Етап 4: дані та помилки

Освойте JSON, файли, `спробувати` і SQLite. Напишіть:

- нотатник у JSON-файлі;
- список справ;
- телефонну книгу;
- простий каталог у SQLite.

### Етап 5: обʼєкти

Вивчіть класи, конструктори, поля, методи та наслідування. Напишіть:

- клас `Користувач`;
- клас `Кошик`;
- систему товарів;
- невелику текстову гру.

### Етап 6: боти

Спочатку зробіть `/start`, потім додайте текстові відповіді, кнопки, callback-и, сесії та базу даних. Після кожної зміни тестуйте бота на одному сценарії.

### Етап 7: власні бібліотеки

Винесіть повторно використовувані функції в окрему бібліотеку, додайте `ucod.toml`, позначте публічні функції через `експорт` і встановіть бібліотеку в тестовий проєкт.

## 21. Як вчитися ефективно

- Пишіть код щодня маленькими частинами, а не великий проєкт одразу.
- Після кожної нової конструкції запускайте найменший приклад.
- Читайте повідомлення про помилки й перевіряйте рядок, на якому вони виникли.
- Даючи змінним і функціям українські зрозумілі назви, ви легше бачите логіку програми.
- Не копіюйте бота цілком: спочатку відтворіть `/start`, потім додайте одну кнопку й одну відповідь.
- Тримайте секрети в `.env`, а не в коді.
- Коли програма повторює один і той самий код, створюйте функцію.
- Коли файл стає великим, створюйте бібліотеку.

## 22. Що ще не є стабільним API

У версії 0.1.3 немає повного bytecode VM, language server, debugger, native compiler, Telegram Gateway, FSM і middleware. Discord підтримує webhook, але не повний Gateway API. Асинхронні конструкції `асинхронна функція` та `чекати` зарезервовані для майбутнього runtime.

Для актуальної точності синтаксису дивіться також [AI_LANGUAGE_SPEC.md](AI_LANGUAGE_SPEC.md), а для готових програм — каталог `examples/`.
