# Стандартна бібліотека

Усі модулі працюють локально та не потребують AI або зовнішнього сервера.

| Модуль | Основні функції |
| --- | --- |
| `Математика` | `округлити`, `абс`, `мін`, `макс`, `корінь`, `пі` |
| `Текст` | `довжина`, `верхній_регістр`, `нижній_регістр`, `замінити`, `розділити`, `об'єднати` |
| `Списки` | `додати`, `видалити`, `відсортувати`, `містить` |
| `JSON` | `розібрати`, `створити` |
| `Файли` | читання, запис, директорії, копіювання, переміщення, розмір |
| `ОС` | поточна директорія, environment variables, перевірка команд |
| `Дата`, `Час` | поточна дата, timestamp, затримка |
| `Випадковість` | випадкове число, ціле, вибір, перемішування |
| `РегулярніВирази` | пошук, заміна, перевірка збігу |
| `Термінал` | введення, очищення, ANSI-колір |
| `Процеси` | запуск локальної команди |
| `Логування` | отримання logger та базове налаштування |
| `HTTP` | GET і JSON POST |
| `БазаДаних` | SQLite: таблиці, вставка, пошук, raw SQL |
| `Telegram` | Bot API polling, команди, текстові фільтри, reply/inline-кнопки, callback queries, фото, документи, редагування та видалення |
